# Mob ESP Mod

**Version:** 1.0.0  
**Author:** ede99  
**Last Updated:** 2025-09-22 

---

## What is Mob ESP Mod

Mob ESP Mod is a client-side mod for Minecraft that highlights mobs (monsters, animals, etc.) through walls or from a distance, giving you a visual “extra sense” of where mobs are. Useful for exploration, mob avoidance, or navigating dangerous areas safely.

---

## Features

- ESP outlines / boxes around mobs  
- Distance display for each mob  
- Toggleable visibility through walls  
- Customizable settings:  
  - Outline color  
  - Max distance for ESP  
  - Types of mobs to highlight (hostile / passive / neutral)  
- Minimal performance impact

---

## Installation

1. Make sure you have a compatible **mod loader** installed (e.g. Fabric) for your Minecraft version.  
2. Download the `.jar` file of Mob ESP Mod.  
3. Move the `.jar` into your mods folder (e.g. `mods/` in your Minecraft installation directory).  
4. Launch Minecraft with the mod loader profile.  
5. In-game, press the configured key to open mod settings (default: `M`). Adjust settings as desired.

---

## Configuration

You can configure the mod via the in-game GUI which can be opend by default with letter "M".
---

## Key Binds

| Function | Default Key |
|----------|-------------|
| Open Mob ESP Settings GUI | `M` |
| Toggle ESP On / Off | `H` |

*(You can change these in the key binds menu.)*

## Compatibility

- Works with Minecraft versions: **1.16.5-1.21+**  
- Compatible with mod loaders: **Fabric**
- Should work with most shader packs and resource packs, though heavy shaders or fancy cores might impact visibility or performance.  
- Not designed for servers where ESP mods are banned; use only where allowed.

---

## Known Issues & Limitations

- Performance drop possible on lower end hardware when rendering many outlines.
